Scope: everything built for the hybrid local pipeline (backend `aether-backend`, frontend
`aether-frontend`, Blender scripts). Method: 56 automated tests, a live run of the golden
project with Gemini, measured facing directions of every placed object, and reading the
code paths the user exercised. "Verified" means a test or a live run proved it today.

## B. Problems found (root cause → fix)

| # | Symptom | Root cause | Severity | Fix |
|---|---|---|---|---|
| 1 | Sofa, beds, wardrobes, counters face the wall | `design/service.py::_wall_aligned_candidates` adds `+ math.pi` to the inward-facing yaw. Measured: 9 of 12 wall-placed objects face away from the room centre; the seed scene's hand-placed objects all face in. The bug pre-dates the pipeline (AI proposals used it too). | High | Remove the extra half turn; add a facing test on the compiled scene. |
| 2 | Rooms feel like a tiny house | (a) Gemini estimates conservative sizes (4×5 living, 2.4×3 kitchen) because the prompt only says "realistic Indian-apartment sizes"; (b) default room sizes are small; (c) the preview camera uses a 24 mm lens at 1.55 m, which exaggerates closeness. | High | Prompt gives typical ranges and asks for generous mid-range sizes; defaults raised ~15 %; preview lens 30 mm; sizes stay editable in Review & Refine. |
| 3 | Cannot replace furniture in the 3D view | The inspector only nudges, rotates and deletes; the `replace_asset` patch op exists on the backend but has no UI; colour edits have no UI; adding from the catalog needs the AI text box. | High | Inspector gains "Replace with…" (catalog picker filtered by type), a colour picker, and an "Add furniture" picker that places via the planner. |
| 4 | Sofa ends up mid-room; chairs against walls | Curtains (2 m wide) are floor obstacles, so they take the window wall and block the sofa; dining set + sofa compete for the same walls in a 4×5 room. | Medium | Curtains become wall-mounted (not an obstacle) while still standing on the floor; wall candidates try more positions; the dining table prefers the wall farthest from the sofa. |
| 5 | Plants render as grey spheres | The planner's per-object colour hint (a palette tone) was applied to plants. | Low | Plants keep their catalog green (fixed, needs re-plan). |
| 6 | Kitchen is bare | No appliance models; counters were only added today. | Medium | Procedural fridge and hob/sink on the counter run. |
| 7 | Doorways have no door leaves | Frames only; a closed leaf would block the film camera path. | Low | Leave open (frames stay). Document. |
| 8 | Backend `--reload` sometimes serves stale routes | uvicorn reload on Windows hangs when the old process has open keep-alive connections. | Low | Launch config runs without `--reload`; restart the backend after backend code changes. |
| 9 | Moodboard felt slow | Frontend polling stopped after a remount; the configured Gemini model was retired. | Fixed | Polling re-arms; model default replaced with fallbacks. |
| 10 | Gemini key appeared in chat | User pasted it. | Note | Rotate the key in AI Studio; `.env` is git-ignored. |

## C. Not built (by design, for later)

- Baked premium GLB for the web viewer (plan M6b).
- Bespoke furniture generation (Meshy path stays off).
- Style-specific furniture families: one catalog of 28 CC0 models serves every style.
- Hosted deployment, auth, PostgreSQL (the job rows are the migration seam).

## D. Fixes applied today (all committed, 57 backend tests green)

1. ✅ Facing direction (B1): the extra half turn removed; regression test `test_wall_placed_furniture_faces_into_the_room`; the golden render shows the sofa facing the room with the coffee table in front and the TV opposite.
2. ✅ Curtains wall-hung and non-blocking; anchor-first placement order (sofa/TV/coffee table, bed/wardrobe, counter/fridge before dining and decor); dining table 0.75 m off the wall so chairs fit; two extra wall positions per edge.
3. ✅ Room sizes: the analysis prompt now gives typical ranges and asks for generous mid-range sizes (the golden run went from a 4.0×5.0 living room to 5.8×4.5 with a separate dining area); defaults raised; preview lens 30 mm.
4. ✅ Kitchen: procedural fridge, hob with burners and a sink with tap on the counter run.
5. ✅ Inspector: "Replace with" (catalog items of the same type, real models first), colour picker, and "Add furniture" (room + catalog piece, placed by the validated planner, then swapped to the chosen model).
6. ✅ Golden project re-analysed, re-planned and re-rendered; docs updated.

Still open from this audit: one dining chair can still land against a wall when the table sits near a corner (B4, minor); doorways stay open (B7); Explore mode does not yet show the procedural counter/fridge shapes as anything but boxes (the Blender renders do).
